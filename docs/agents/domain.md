# 도메인 문서

## 코드베이스를 조사하기 전에 읽을 문서

- 루트의 `CONTEXT.md`
- 작업 영역과 관련된 `docs/adr/` 문서

파일이 아직 없다면 별도 경고 없이 작업을 계속한다. 도메인 용어나 설계 결정이 실제로
확정될 때 `domain-modeling` 스킬이 문서를 생성한다.

## 구조

이 저장소는 single-context 구조를 사용한다.

```text
/
├── CONTEXT.md
├── docs/adr/
└── src/
```

## 도메인 용어

이슈 제목, 리팩터링 제안, 가설, 테스트 이름에는 `CONTEXT.md`에 정의된 용어를
사용한다. 정의되지 않은 용어가 필요하다면 기존 표현을 다시 확인하거나
`domain-modeling`으로 용어를 확정한다.

## ADR 충돌

기존 ADR과 모순되는 변경을 제안할 때는 해당 충돌을 명시적으로 밝힌다. 기존 결정을
조용히 덮어쓰지 않는다.
