# Triage 라벨

| 스킬의 역할 | GitHub 라벨 | 의미 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 유지관리자가 이슈를 평가해야 함 |
| `needs-info` | `needs-info` | 제보자의 추가 정보를 기다리는 중 |
| `ready-for-agent` | `ready-for-agent` | 명세가 충분해 AFK 에이전트가 처리 가능 |
| `ready-for-human` | `ready-for-human` | 사람의 작업이나 판단이 필요 |
| `wontfix` | `wontfix` | 처리하지 않기로 결정 |

스킬이 역할을 언급하면 이 표의 GitHub 라벨을 사용한다.
